## 📂 Cấu trúc Repository

### 1. [Báo cáo nhóm về Logistic Regression](./Báo%20cáo%20nhóm%20về%20Logistic%20Regression/)
* **NhomX.ipynb**: Báo cáo bài tập lớn hoàn chỉnh:
  * So sánh 3 hàm Loss function: **Logistic Loss (±1)**, **Binary Cross-Entropy (0/1)**, và **Mean Squared Error (MSE)**.
  * Thuật toán tối ưu: **Stochastic Gradient Descent (SGD)** tự cài đặt từ đầu (From Scratch).
  * Bộ dữ liệu: **1000 quả** có độ nhiễu tự nhiên và kiểm thử độc lập trên 50 quả ngẫu nhiên mới toanh.
* **Logistic_Regression_Cross_Entropy.ipynb**: Mô hình Hồi quy Logistic chuyên sâu độc lập với hàm mất mát **Binary Cross-Entropy (BCE)**:
  * Đầy đủ chứng minh toán học đạo hàm triệt tiêu của Sigmoid.
  * Bản đồ xác suất và đường ranh giới phân lớp (Decision Boundary).
  * Ma trận nhầm lẫn (Confusion Matrix) và tính năng dự đoán quả mới thực tế.

### 2. [Code chương 2](./Code%20chương%202/)
